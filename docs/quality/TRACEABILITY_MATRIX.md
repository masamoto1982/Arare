# Traceability Matrix

Requirement → implementation → verification evidence, as
`PLAN_OVERVIEW.md` requires and `npm run check:traceability`
(`scripts/check-traceability-matrix.mjs`) checks in both directions.

The ID classes are `STANDARDS.md`'s. Arare writes this matrix before the code
it traces: a requirement row comes first, and code citing an ID the matrix
lacks fails the check.

## Matrix

The requirement rows are generated from `spec/requirements.json` by
`scripts/generate-requirements.mjs` and are not edited here; `npm run
check:requirements` checks the registry and that this block is current. Until
Phase 2 no requirement has an implementation; the verification column names
the Lean theorems that prove it (`formal/Arare/`, AR-VER-101 to AR-VER-106)
and what is planned beyond them.
